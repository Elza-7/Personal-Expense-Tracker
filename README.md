# 💰 Personal Expense Tracker

A beginner-friendly Python command-line application that helps users manage their daily expenses. Users can add, view, edit, delete, search, and track expenses with automatic JSON file storage.

## 🚀 Features

- **Add Expenses** – Add an expense with its name, amount, and category.
- **View Expenses** – Display all saved expenses.
- **Total Spending** – Calculate the total amount spent.
- **Delete Expenses** – Remove an unwanted expense.
- **Edit Expenses** – Update expense name, amount, or category.
- **Search by Name** – Find expenses using their names.
- **Search by Category** – Find expenses using their categories.
- **Data Persistence** – Save and load expenses using JSON.
- **Input Validation** – Handle invalid amounts and empty inputs.

## ⚙️ How to Run

**1. Clone the repository**

```bash

```

**2. Open the project folder**

```bash
cd Personal-Expense-Tracker
```

**3. Run the application**

```bash

```
